# Sentinel Edge Dashboard

A lightweight, zero-build dashboard for observing the two-tier AIOps pipeline.

## Features
- **Fleet View**: Live health states across collectors in multiple regions and tenants.
- **Four Health States**: `Excellent`, `Good`, `Fair`, `Poor` with stated transition rationales.
- **Egress Proof Panel**: Direct display of raw JSON payloads demonstrating zero secret leakage.
- **AIOps Why Drawer**: Explainable root-cause diagnosis, signal attribution weights, and confidence score.
- **Human-in-the-Loop Remediation**: Gated approval workflow with policy check, simulation execution, and rollback.

## Usage
Simply open `index.html` in any web browser or view it via Docker Compose (`http://localhost:3000`).
